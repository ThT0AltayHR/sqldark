SQLDark

An advanced SQL injection testing framework for security professionals. Fast, modular, terminal-only — a stronger alternative to sqlmap, built for Termux & Linux. For authorized penetration testing and education.

Get started ★ Star on GitHub
pip install sqldark

Install & run

Python 3.8+. Works on Termux, Linux, and WSL.

# install
$ pip install sqldark

# detect everything on a parameter
$ sqldark -u "https://shop.example/product?id=1"

# fingerprint + dump the whole DB, save a session, export to zip
$ sqldark -u "https://shop.example/item?id=1" --dump-all --session shop --export

# get through a WAF automatically
$ sqldark -u "https://shop.example/item?id=1" --auto-tamper --level 3
